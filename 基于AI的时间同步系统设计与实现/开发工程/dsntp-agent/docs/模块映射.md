# 模块映射与实现清单（DSNTP-DRS-002）

## 状态机—报文—源码对照

| 转移/场景 | 事件 | 报文 | 主要源码 |
|-----------|------|------|----------|
| Init→SyncWait | Start | START_SYNC 0x01 | `fsm.c` / `agent.c` |
| Collecting | 采样 | TIME_REQ/RESP 0x02/03 | `measure.c` / `agent.c` TODO |
| Consensus | 广播确认 | RESULT/ACK 0x04/07 | `consensus.c` / `agent.c` TODO |
| Estimating | 本地拟合 | 无 | `measure.c` regress |
| Running | 输出 | IF-APP | `clock.c` / `api/local_sock.c` |
| PeerFaultConfirm | 对端故障 | FAULT_NOTIFY **0x06** | `recover.c` |
| Recovering | 重入 | ANNOUNCE/ACK 0x05/08 | `recover.c` |
| Ext_Sync | 单向校时 | EXT_TIME_IN（本地） | 待实现 |

完整强制表见 [状态机报文对照.md](状态机报文对照.md)（DRS §6.3）。

## 建议编码顺序

1. `protocol` payload 大端字段（TIME_* / RESULT / ACK）
2. `agent` Collecting 真实收发 + 超时
3. `agent` Consensus 广播 + ACK 法定人数
4. `crypto` OpenSSL
5. `recover` 接入 agent 事件
6. Ext_Sync / 自适应周期
