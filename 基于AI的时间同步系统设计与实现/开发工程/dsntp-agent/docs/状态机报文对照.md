# 状态机—报文对照（DRS-002 §6.3）

> 实现检查清单。缺报文类型或 Type 冲突视为不满足协议基线（FR-FSM-004 / AC-18）。

| 状态转移 / 场景 | 触发事件 | 报文 / 接口 | 覆盖说明 |
|-----------------|----------|-------------|----------|
| Init→SyncWait | Start | START_SYNC(0x01) | 临时 Leader 广播；验签后进入 SyncWait |
| SyncWait→Collecting | TimerTick | 无网络报文 | 本地定时器 |
| Collecting 内 | 采样交换 | TIME_REQ(0x02)/TIME_RESP(0x03) | 获取 T0～T3；超时→PeerFaultSuspect |
| Collecting→Consensus | CollectDone | 无（本地） | 收齐或超时结束收集 |
| Consensus 内 | 广播/确认 | CONSENSUS_RESULT(0x04)/CONSENSUS_ACK(0x07) | ≥2f+1 ACK → ConsensusDone |
| Consensus→Estimating | ConsensusDone | 无（本地） | — |
| Estimating→Running | EstimateDone | 无（本地） | 滑动窗口拟合 |
| Running→SyncWait | TimerTick | 无网络报文 | Round++ |
| 对端故障确认 | PeerFaultConfirm | FAULT_NOTIFY(**0x06**) | ≥f+1 后逻辑剔除；检测方保持主闭环 |
| （故障节点）→Fault | LocalFaultDetect | 可收 FAULT_NOTIFY | **仅**本机故障节点进入 Fault |
| Fault→Recovering | RecoverDone | 无（链路恢复） | — |
| Recovering 内 | 对齐准备 | 监听 RESULT/RESP；发 RECOVER_ANNOUNCE(0x05) | 静默≥2 周期 |
| Recovering→SyncWait | AlignSyncDone | RECOVER_ACK(0x08) | ≥2f+1 ACK 后重入 |
| SyncWait↔Ext_Sync | ExternalTimeValid / ExtSyncDone | 本地 EXT_TIME_IN 帧 | 不占用 P2P Type 空间 |
| Running→Stopped | Stop | 无网络报文 | — |

## Type 速查

| Type | 名称 | 强制验签 |
|------|------|----------|
| 0x01 | START_SYNC | 是 |
| 0x02 | TIME_REQ | 默认可配 |
| 0x03 | TIME_RESP | 默认可配 |
| 0x04 | CONSENSUS_RESULT | 是 |
| 0x05 | RECOVER_ANNOUNCE | 是 |
| **0x06** | **FAULT_NOTIFY** | 是 |
| 0x07 | CONSENSUS_ACK | 默认可配 |
| 0x08 | RECOVER_ACK | 默认可配 |

公共头：Magic=`0x5453594E`（"TSYN"），Version=`0x02`，Signature=**64B**。
