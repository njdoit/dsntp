# dsntp-wide — 宽同步层工程骨架（L4）

| 项目 | 内容 |
|------|------|
| 里程碑 | M5～M6 |
| 需求 | FR-NTP-004～008、IF-NTP、接入矩阵 |
| 状态 | **模板与采集器占位** |

## 职责

- 为交换机 / 路由器 / 防火墙 / 摄像机提供 NTP/SNTP 开局模板
- （可选）偏差采集器占位：SNMP / ONVIF → 上报 ctl

## 红线

1. 客户端 **禁止** 指向外网 NTP
2. 生产配置 **双** `ntp server`（主备网关）
3. 不反向改写精同步共识

## 目录

```text
dsntp-wide/
├── README.md
├── templates/          # 设备侧 NTP 配置片段
└── collector/          # 可选偏差采集（占位）
```

|------|------|
