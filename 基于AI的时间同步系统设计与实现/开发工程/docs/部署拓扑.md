# 部署拓扑说明

示例文件：`deploy/topology/poc-n5.yaml`（\(n=5,\ f=1\)）。

## 推荐最小 PoC

| 角色 | 数量 | 组件 |
|------|------|------|
| 共识节点 | 3～5 | `dsntp-agent` |
| NTP 网关 | 2（主备） | `dsntp-agent(role=gateway)` + `dsntp-ntp` |
| 管控 | 1 | `dsntp-ctl` |
| 宽同步样机 | ≥1 交换机或摄像机 | NTP 指向双网关 |

## systemd 单元

| 单元 | 用途 |
|------|------|
| `deploy/systemd/dsntp-agent.service` | 精同步 |
| `deploy/systemd/dsntp-ctl.service` | 管控 |
| `deploy/systemd/dsntp-time-shim.service` | 喂 chrony |

## 网络口

| 端口 | 用途 | 防火墙 |
|------|------|--------|
| UDP 47500 | TSYN 数据面 | 仅 Agent 互联 |
| TCP 50051 | gRPC 管控 | Agent→Server |
| TCP 8080 | HTTP 控制台 | 运维网段 |
| UDP 123 | NTP | 客户端→网关；禁外网 NTP |

## 失败域

- ctl 宕机 → Agent 继续共识；恢复后补报（FR-ARCH-003 / NFR-AVL-002）
- 单网关宕机 → 客户端走备网关
- ≤f 个 Agent 故障 → 共识维持（\(n\geq 3f+1\)）
