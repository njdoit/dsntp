# 系统架构与分层（系统级工程骨架）

| 项目 | 内容 |
|------|------|
| 文档 | DSNTP 系统级工程骨架 · 架构说明 |
| 基线 | DSNTP-DRS-002 V2.0 |
| 配套 | CTX-001 V2.2；本目录属 `开发工程/docs` |

## 1. 四层逻辑

```text
L1 管控层     dsntp-ctl      gRPC:50051 / HTTP:8080
L2 精同步层   dsntp-agent    UDP:47500 TSYN（精度路径）
L3 时间出口   dsntp-ntp      chrony + time-shim → UDP:123
L4 宽同步层   dsntp-wide     交换机/摄像机 NTP/SNTP 客户端模板
```

## 2. 平面分离（FR-ARCH）

| 平面 | 组件 | 可否影响 Tc |
|------|------|-------------|
| 数据面 | Agent↔Agent TSYN | 是 |
| 管控面 | Agent Reporter ↔ ctl | **否** |
| 时间出口 | ntp shim/chrony | **否**（只读合成时间） |
| 宽同步 | 异构 NTP 客户端 | **否** |

## 3. 仓库落点

| 层 | 目录 | 里程碑 |
|----|------|--------|
| 契约 | `api/` | 全里程碑共用 |
| 部署 | `deploy/` | M6 为主，骨架先行 |
| L2 | `dsntp-agent/` | M1～M3 |
| L1 | `dsntp-ctl/` | M4 |
| L3 | `dsntp-ntp/` | M5 |
| L4 | `dsntp-wide/` | M5～M6 |

参考实现（只读）：`D:\dsntp\dtc-c`。

## 4. 红线速查

- Magic = `0x5453594E`（"TSYN"）
- FAULT_NOTIFY = `0x06`
- Signature = `64B`
- 样本 &lt; 2f+1 → 不更新 Tc
- Server / NTP **不得**改写 Tc
