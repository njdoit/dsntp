# 系统接口矩阵（IF-*）

基线：DRS-002 §9。权威契约源：`开发工程/api/`。

| 接口 | 协议 | 端点 / 路径 | 提供方 | 消费方 | 目录 |
|------|------|-------------|--------|--------|------|
| IF-TSYN | UDP 47500 | TSYN Header+Payload+Sig | Agent | Agent | `dsntp-agent` |
| IF-APP | UDS | `/var/run/time-agent.sock` | Agent | 本机应用 / time-shim | `dsntp-agent` / `dsntp-ntp` |
| IF-CTL gRPC | gRPC 50051 | `ControlPlane.*` | ctl | Agent Reporter | `api/agent.proto` |
| IF-CTL HTTP | HTTP 8080 | `/api/v1/*` | ctl | 运维 | `api/openapi-v1.yaml` |
| IF-NTP | UDP 123 | NTP/SNTP | ntp 网关 | 宽同步设备 | `dsntp-ntp` / `dsntp-wide` |

## 方向约束

1. ctl → Agent：仅配置/指令（含 Ext_Sync），**无授时权威**。
2. Agent → ctl：只读观测（含 `consensus_tc` 字段），Server 不得回写。
3. time-shim → chrony：只喂合成时间；禁止 `server pool.ntp.org` 一类外源。
