## 1. 目的

在 Agent 可编译骨架之上，落盘**系统级**工程骨架，使 L1～L4、共享契约与部署拓扑具备统一入口，避免只做精同步子系统。

## 2. 骨架总览

```text
开发工程/                          ★ 系统级官方根
├── api/agent.proto                IF-CTL gRPC
├── api/openapi-v1.yaml            IF-CTL HTTP
├── deploy/topology/poc-n5.yaml    n=5,f=1 拓扑
├── deploy/systemd/*.service
├── deploy/docker-compose.yml
├── docs/{系统架构,接口矩阵,部署拓扑}.md
├── Makefile
├── dsntp-agent/                   L2 已有 C11 骨架
├── dsntp-ctl/                     L1 Go HTTP 可运行骨架
├── dsntp-ntp/                     L3 chrony + shim 源码骨架
└── dsntp-wide/                    L4 NTP 开局模板
```


## 6. 红线（系统级强制）

| ID | 约束 |
|----|------|
| R1 | Magic=`0x5453594E`；FAULT=`0x06`；Sig=`64B` |
| R2 | Server/NTP/宽同步不得改写 \(T_c\) |
| R3 | &lt;2f+1 样本不更新 \(T_c\) |
| R4 | Server 宕机不中断共识与 NTP 出口 |
| R5 | 客户端禁止外网 NTP |
