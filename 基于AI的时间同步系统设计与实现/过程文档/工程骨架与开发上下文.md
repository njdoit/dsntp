## 2. 系统骨架总览（对齐 DRS-002 §4）

### 2.1 逻辑分层

```text
┌─────────────────────────────────────────────────────────────┐
│  管控层  dsntp-ctl（占位）  gRPC:50051 / HTTP:8080            │
│  配置·密钥·汇聚·告警·审计·控制台                               │
└──────────────▲──────────────────────────┬───────────────────┘
               │ 管控面（允许秒级延迟）      │ 配置/指令下发
┌──────────────┼──────────────────────────┼───────────────────┐
│              │  精同步层  dsntp-agent     │                   │
│  Agent◄─UDP:47500 TSYN─►Agent …          │                   │
│              │  get_synced_time / UDS     │                   │
└──────────────┼───────────────────────────┘                   │
               ▼
┌─────────────────────────────────────────────────────────────┐
│  时间出口层  dsntp-ntp（占位） chrony + time-shim             │
└───────────────────────────────┬─────────────────────────────┘
                                ▼ UDP:123
┌─────────────────────────────────────────────────────────────┐
│  宽同步层  交换机 / 路由器 / 防火墙 / 摄像机（NTP/SNTP）        │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 管控面 / 数据面分离（红线）

| 平面 | 协议 | 影响授时精度 | 实现位置 |
|------|------|--------------|----------|
| 数据面 | UDP 47500 / TSYN | **是** | `dsntp-agent` 热路径（参考：`dtc-c`） |
| 管控面 | gRPC/HTTPS | **否** | `dsntp-ctl` + Agent Reporter；Server 宕机不得停共识 |

**FR-ARCH-002/003/004**：Server 不参与、不改写 \(T_c\)；Agent 本地缓存配置可离线共识；Reporter **禁止**在 UDP 热路径阻塞调用管控 I/O。

### 3.2 模块 ↔ DRS-002 需求映射

| 模块 | DRS 需求 | 骨架进度 | 备注 |
|------|----------|----------|------|
| protocol | §7 IF-TSYN、OC-01～03 | Header/Packet 可用 | Magic=TSYN；FAULT=**0x06**；Sig=**64B** |
| clock | FR-CLK、FR-SYN-002 | 单调钟 + 合成公式 | |
| fsm | §6 FR-FSM | 合法转移；PeerFault 不改本机态 | FR-FSM-002/004 |
| measure | FR-MEAS、FR-SYN-001 | RTT/θ̂ + 回归 | |
| consensus | FR-CNS | 中位数；&lt;2f+1 不更新 Tc | |
| recover | FR-FLT | 投票/静默/ACK API | agent 联调待填 |
| crypto | FR-SEC | **占位** | 对接 OpenSSL 为 M2 |
| net | UDP 47500 | bind/send/recv | |
| config | DR-003 | key=value | |
| api | IF-APP | UDS 骨架 | |
| agent | §5.7 / §6.4 | 状态机主循环 + **TODO 填空** | Collecting/Consensus 待接报文 |
| reporter | FR-CTL | **未建** | M4 |
| ntp-shim | FR-NTP | **未建于 agent** | M5；角色 gateway 可预留 |

### 3.3 内部数据流

```text
timer tick
    │
    ▼
Collecting ──TIME_REQ/RESP──► measure(RTT, θ̂)
    │
    ▼
Consensus ──median──► Tc（不足 2f+1 则保持旧 Tc）
    │                    + CONSENSUS_ACK ≥2f+1
    ▼
Estimating ──regress──► α̂, β̂
    │
    ▼
Running ──► clock.synced_ns ──► UDS (IF-APP)
                │
                └──（M4）Reporter 快照 ──管控面──► dsntp-ctl
```

## 4. 状态机—报文对照（DRS §6.3，实现检查清单）

| 状态转移 / 场景 | 事件 | 报文 / 接口 | 验收要点 |
|-----------------|------|-------------|----------|
| Init→SyncWait | Start | START_SYNC 0x01 | 验签 |
| Collecting | 采样 | TIME_REQ/RESP 0x02/03 | T0～T3；超时→PeerFaultSuspect |
| Consensus | 广播确认 | RESULT/ACK 0x04/07 | ≥2f+1 ACK |
| PeerFaultConfirm | 对端故障 | FAULT_NOTIFY **0x06** | ≥f+1；检测方不进 Fault |
| Recovering | 重入 | ANNOUNCE/ACK 0x05/08 | 静默≥2；≥2f+1 ACK |
| Ext_Sync | 单向校时 | 本地 EXT_TIME_IN | 不占 P2P Type |
| Estimating / Running 闭环 | 本地 | 无网络报文 | 合成钟单调 |

**AC-18**：上表依赖通信的转移均须有编解码与联调用例。

## 6. M1～M6 接续路径与当前缺口

| 阶段 | 内容 | 落点 | 当前缺口 |
|------|------|------|----------|
| M1 | 最小闭环 | dsntp-agent | agent Collecting/Consensus 真实收发；payload 大端 |
| M2 | 安全与容错 | dsntp-agent | OpenSSL 签名；FAULT/RECOVER 接入主循环；AC-18 |
| M3 | 完整算法 | dsntp-agent | 多层共识轻量路径、周期自适应、Ext_Sync |
| M4 | 管控面 | dsntp-ctl + Reporter | 目录占位，业务未实现 |
| M5 | NTP 异构 | dsntp-ntp | 目录占位，shim 未实现 |
| M6 | 工程硬化 | 部署/验收 | RT、72h、70% 流量、资源 |

建议编码顺序（Agent）：payload 编解码 → Collecting 收发 → Consensus ACK → crypto → recover 接线 → Ext_Sync / 自适应。

## 7. 协议与红线速查（DRS §7 / §12）

| 项 | 定稿 |
|----|------|
| Magic | `0x5453594E`（"TSYN"） |
| Version | `0x02` |
| 结构 | Header(16B) + Payload + Signature(**64B**) |
| FAULT_NOTIFY | Type=**0x06**（禁止 0x03） |
| 强制验签 | START_SYNC、CONSENSUS_RESULT、FAULT_NOTIFY、RECOVER_ANNOUNCE |
| PeerFault | **不**导致本机进入 Fault |
| 样本 &lt; 2f+1 | **不更新** \(T_c\) |
| AlphaPpm | `alpha = (AlphaPpm/1e6)×1e-6`（IF-TSYN-015） |
| Server | 不改 \(T_c\)；宕机不中断共识与 NTP |

OC-01～08 全文见 DRS-002 §12。
