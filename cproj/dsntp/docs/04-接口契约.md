# 04 — 接口契约（Interface）

权威契约源：`api/agent.proto`、`api/openapi-v1.yaml`；线格式见 `include/dsntp/protocol.h`。

## IF-TSYN（Agent ↔ Agent）

| 项 | 定稿 |
|----|------|
| 传输 | UDP，默认 **47500** |
| 结构 | Header(**16B**) + Payload + Signature(**64B**) |
| Magic | `0x5453594E` ("TSYN") |
| Version | `0x02` |
| 字节序 | 大端（`dsntp_*_encode`） |
| FAULT_NOTIFY | Type=**0x06**（禁止 0x03） |

强制验签：`START_SYNC`、`CONSENSUS_RESULT`、`FAULT_NOTIFY`、`RECOVER_ANNOUNCE`。

AlphaPpm（IF-TSYN-015）：

```c
alpha = (AlphaPpm / 1e6) * 1e-6;  /* dsntp_alpha_from_wire */
```

## IF-APP（本机应用 / shim ↔ Agent）

| 项 | 定稿 |
|----|------|
| 机制 | Unix Domain Socket（示例 `/tmp/time-agent.sock`） |
| 语义 | 连接后 Agent 写出一行 `synced_ns\n` |
| API | `dsntp_clock_synced_ns` / `get_synced_time` 等价 |

## IF-CTL（Agent ↔ Server）

| 面 | 端点 | 骨架状态 |
|----|------|----------|
| HTTP | `GET /api/v1/health` | `dsntp-ctl` 已实现 |
| HTTP | `GET /api/v1/nodes` | 已实现 |
| HTTP | `POST /api/v1/ingest/report` | 已实现（naive JSON） |
| HTTP | `GET /api/v1/events` | 空列表占位 |
| gRPC | `ControlPlane.ReportStream` 等 | proto 契约；C 运行时未接 |

TimeReport 核心字段：`node_id, seq, monotonic_ns, synced_ns, consensus_tc, round, fsm_state, …`（只读观测；Server 不得回写 Tc）。

C 侧上报桩：`dsntp_ctl_post_report`（`ctl_client.h`）。

## IF-NTP（网关 ↔ 异构设备）

| 项 | 要求 |
|----|------|
| 对外 | UDP **123** 标准 NTP/SNTP（chrony） |
| shim | 读 IF-APP，写 chrony SOCK（`time-shim` TODO） |
| 禁止 | 客户端访问外网 NTP；网关禁止外源取时 |

## Ext_Sync（本地帧，非 P2P Type）

Magic `EXTI`；不占用 `0x01`～`0x08`（OC-08）。M3 再接线。
