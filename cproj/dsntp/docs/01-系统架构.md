# 01 — 系统架构（System）

基线：DRS-002 §4。工程根：`cproj/dsntp/`。

## 逻辑分层

```text
L1 管控层     apps/ctl (+ api/)     gRPC 契约 / HTTP:8080
L2 精同步层   apps/agent + lib/     UDP:47500 TSYN
L3 时间出口   apps/time-shim        chrony SOCK → UDP:123
L4 宽同步层   交换机/摄像机等        NTP/SNTP 客户端
```

## 数据面 vs 管控面

| 平面 | 协议 | 影响授时精度 | 代码位置 |
|------|------|--------------|----------|
| 数据面 | UDP 47500 / TSYN | **是** | `lib` + `apps/agent` 热路径 |
| 管控面 | HTTP JSON（P0）/ gRPC（契约） | 否 | `apps/ctl` + `apps/agent/reporter.c` |

**FR-ARCH-002**：ctl 不得参与 P2P 共识、不得改写 \(T_c\)。  
**FR-ARCH-003**：Server 不可达时 Agent 用本地配置继续共识。  
**FR-ARCH-004**：Reporter 禁止在 UDP 回调中阻塞调用管控 I/O。

## Agent 软件分层（§4.4）

| 层 | 职责 | 模块 |
|----|------|------|
| L1 本地逻辑时钟 | `CLOCK_MONOTONIC` | `clock` |
| L2 分布式共识 | 采样、中位数 \(T_c\) | `measure` `consensus` `protocol` `net` |
| L3 合成与漂移校正 | α̂/β̂、合成钟 | `measure` 回归 + `clock` |
| L4 应用/运维输出 | UDS、Reporter、Ext_Sync | `api_local` `reporter` |

## 部署角色

| 角色 | 配置 | 说明 |
|------|------|------|
| `consensus_only` | `role=consensus_only` | 禁用外源对时 |
| `gateway` | `role=gateway` | 允许 chrony/shim **仅**消费本机合成时间（OC-06） |

推荐规模：\(n=5,\ f=1\)；见 `deploy/topology/poc-n5.yaml`。
