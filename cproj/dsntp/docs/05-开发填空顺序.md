## 建议编码顺序

1. **payload 联调**：已提供 0x01～0x08 编解码；补单元测试覆盖 FAULT/ACK。
2. **Collecting**：并发 TIME_REQ，超时 22ms，有效样本入表。
3. **Consensus**：中位数 + RESULT/ACK 法定人数。
4. **Estimating + Running**：回归与 UDS 可读单调合成时间 → **M1 出口 AC-01**。
5. **crypto + FAULT/RECOVER** → **M2**（AC-03/04/07/17/18）。
6. **多层共识 / 自适应 / Ext_Sync** → **M3**。
7. **Reporter + ctl 持久化/告警** → **M4**（AC-10/11/12）。
8. **shim + chrony + 宽同步模板** → **M5**（AC-13/14）。
9. **RT / 72h / 70% 流量 / 资源** → **M6**（AC-05/06/08）。
