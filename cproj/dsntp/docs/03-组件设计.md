# 03 — 组件设计（Component）

对齐 NFR-RES-004 / FR-ARCH-004 / FR-CTL-001。

## 建议线程模型

| 组件/线程 | 职责 | 约束 |
|-----------|------|------|
| 主控 / FSM | 状态推进、轮次、调用 measure/consensus | 热路径；M6 可 SCHED_FIFO |
| 网络收 | UDP recv → 入队 | **禁止** gRPC/HTTPS |
| 网络发 | 出队 → sendto | 低延迟 |
| 定时器 | TimerTick / CollectTimeout(22ms) | 高精度优先 |
| Reporter | 无锁快照读 → HTTP 上报 | 独立线程；`reporter.c` 骨架已起线程 |
| UDS poll | `dsntp_api_local_poll` | 可挂主循环 |

当前骨架：收发与定时器仍折叠在 `dsntp_agent_run` 单线程中；M1 接线后宜拆队列。

## 共享状态

| 数据 | 写者 | 读者 |
|------|------|------|
| FSM state | 主控 | Reporter / 日志 |
| α̂ β̂ / last_sync_c | Estimating | UDS / Reporter / shim |
| Tc / round | Consensus | Reporter（只读观测） |
| peer 样本表 | Collecting | Consensus |

约定：热路径写、旁路读 → 原子/`seqlock` 或短临界区；**持锁不做**管控网络 I/O。

## 可执行组件

| 二进制 | 组件边界 |
|--------|----------|
| `dsntp-agent` | 精同步 + 本机 UDS + Reporter 桩 |
| `dsntp-ctl` | 管控汇聚 HTTP 最小面 |
| `dsntp-time-shim` | 合成时间 → chrony（M5 填 SOCK 帧） |
| `libdsntp_core.a` | 协议/算法/时钟/FSM/网络 |
