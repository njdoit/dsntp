## 依赖方向（禁止逆向）

```text
apps/agent  →  dsntp_core (lib)
apps/time-shim → (UDS) agent；不依赖 consensus 内部
apps/ctl    → 独立进程；只收观测，不写 Tc
reporter    → ctl_client；不得被 net/udp 同步调用
```

## 状态机 ↔ 报文（摘要）

完整对照见 DRS §6.3 与 [04-接口契约.md](04-接口契约.md)。

| 场景 | Type |
|------|------|
| Init→SyncWait | START_SYNC 0x01 |
| Collecting | TIME_REQ/RESP 0x02/0x03 |
| Consensus | RESULT/ACK 0x04/0x07 |
| PeerFaultConfirm | FAULT_NOTIFY **0x06** |
| Recovering | ANNOUNCE/ACK 0x05/0x08 |
